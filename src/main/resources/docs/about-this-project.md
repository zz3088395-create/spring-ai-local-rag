# 关于这个项目

spring-ai-local-rag 是一个用 Spring Boot 和 Spring AI 搭的本地 AI 助手。所有模型调用都发给同一台机器上的 Ollama，数据不出电脑，也没有按 token 计费的成本。

## 整体架构

后端分三部分。对话服务把人设、更早对话的滚动摘要、知识库里最相关的片段和最近几条消息组装成提示词，再把模型的回答通过 Server-Sent Events 流式推给浏览器。会话记忆原文保留最近六条消息，更早的内容由模型自己压缩成一段简短摘要，所以无论对话多长，提示词长度都是有界的。向量存储用 bge-m3 模型给每个入库的段落做向量化，查询时用暴力余弦相似度，几千个片段以内足够。

## 记忆压缩

压缩在一次回答结束后触发，条件是原文历史达到十二条或更多。最旧的消息会连同上一版摘要一起发给模型，要求合并成不超过 150 字的新摘要，保留姓名、偏好、决定和尚未解决的问题。新摘要生成后替换掉那些旧消息。摘要在后台线程上运行，用户不需要等待；如果失败，什么都不会被删除。

## 检索

文本按空行切成大约 400 字符的块。超过这个长度的段落会被切开，切口处保留 60 个字符的重叠，边界上的句子至少在一块里是完整的。查询时把问题向量化，按余弦相似度取前三个片段，低于 0.30 分的丢掉，剩下的连同来源文件名一起作为参考资料注入 system prompt。

## 换模型

对话模型和向量模型都是 application.yml 里的普通配置。把 base-url 指向远程的 OpenAI 兼容接口，或者把 Ollama starter 换成 OpenAI、Anthropic 的 starter，都不需要改代码，因为服务层只依赖 Spring AI 的 ChatClient 和 EmbeddingModel 抽象。
